# العقل الخوارزمي

موقع تعليمي عربي متجاوب بالكامل، مبني باستخدام Next.js App Router وReact وTypeScript وPostgreSQL وDrizzle ORM. الواجهة RTL افتراضيًا، بخط IBM Plex Sans Arabic محلي، وأيقونات Lucide وانتقالات Framer Motion تحترم تفضيل تقليل الحركة.

## التشغيل المحلي

يتطلب Node.js 20.9+ (يُفضّل 22) وقاعدة PostgreSQL.

1. ثبّت الاعتماديات: `npm install`.
2. أنشئ `.env` اعتمادًا على `.env.example`، واضبط `DATABASE_URL`.
3. طبّق المخطط: `npx drizzle-kit migrate` (أو `npx drizzle-kit push` للتطوير السريع).
4. شغّل `npm run dev` وافتح الموقع على المنفذ الذي يعرضه Next.js.

يُهيّأ بنك الأسئلة تلقائيًا وبأمان عند أول طلب للأسئلة أو تصحيح إجابة. لا حاجة لمفتاح API خارجي. الصفحات التسويقية والتعليمية لا تحتاج إلى استعلام قاعدة بيانات أثناء البناء.

## النشر على Vercel أو Netlify

- استورد مستودع Git إلى مشروع Next.js على المنصة.
- اضبط متغير البيئة `DATABASE_URL` على رابط PostgreSQL مُدار، مثل Neon، مع تفعيل TLS وفق متطلبات المزوّد.
- أمر البناء `npm run build`. يستخدم Netlify امتداد Next.js الرسمي تلقائيًا.
- نفّذ `npx drizzle-kit migrate` مرة واحدة من بيئة موثوقة لديها رابط قاعدة البيانات نفسه قبل استقبال المستخدمين.
- يمكنك ضبط `SITE_URL` على عنوان نطاقك النهائي. يُكتشف عنوان النشر على Vercel وNetlify تلقائيًا عند غيابه.
- انشر الموقع عبر HTTPS كي تعمل جلسة الضيف الآمنة كما ينبغي.

هذا موقع ويب قياسي، وليس غلاف تطبيق أصلي. الروابط صفحات فعلية قابلة للمشاركة: `/`, `/map`, `/challenges`, `/achievements`, `/leaderboard`.

## بنية التطبيق

- `src/data/questions.json`: المصدر الكامل للأسئلة، يشمل المفاتيح والإجابات المقبولة والتفسير. **لا تستورده في مكوّن عميل.**
- `src/data/question-index.json`: فهرس عام منزوع الإجابات والتفسير، يستخدمه المتصفح لعرض الأسئلة.
- `src/lib/curriculum.ts`: الفصول والمراحل والرتب ومساعدات التقدّم، دون مفاتيح إجابات.
- `src/lib/server/question-bank.ts`: تحميل البنك الكامل على الخادم فقط.
- `src/db/schema.ts`: الجداول الأربعة: الفصول، الأسئلة، المتعلمون، المحاولات. محتوى السؤال والتقدّم مخزّن في JSONB قابل للتوسعة.
- `src/components/quiz.tsx`: الاختيار من متعدد، صواب/خطأ، الإدخال النصي، الشرح الفوري، إعادة المحاولة، المراجعة وملخص الإنجاز.
- `src/components/progress-provider.tsx`: مزامنة آمنة بعد التركيب، ونسخة محلية في localStorage. لا يقرأ المتصفح تخزينه أثناء التصيير على الخادم.

يحتوي الإصدار الأول على ٤ فصول، و١٦ مرحلة، و٤٨ سؤالًا، و٦ تحديات يومية تتناوب في مجموعتين من ثلاثة أسئلة عند منتصف الليل UTC.

## التقدّم والنقاط

- لكل سؤال مكافأة خبرة تُمنح مرة واحدة فقط. الأسئلة السابقة قابلة للمراجعة دون تكرار النقاط.
- تُفتح المراحل بالترتيب بعد إكمال جميع أسئلة المرحلة السابقة. التحديات اليومية مستقلة عن فتح الفصول.
- يحتسب الالتزام وفق أيام UTC التي سُجّلت فيها محاولة، ويحفظ أفضل سلسلة أيضًا.
- الدقة هي نسبة المحاولات الصحيحة إلى إجمالي المحاولات، بما فيها المراجعات.
- الرتب: مبتدئ (٠)، مفكّر (١٠٠)، محلّل (٣٠٠)، خوارزمي (٦٠٠)، عقل خارق (١٠٠٠).
- تُستخدم معاملة قاعدة بيانات وقفل صف المتعلّم لمنع احتساب المكافأة مرتين عند الطلبات المتزامنة.
- لوحة الشرف تعرض بيانات المتعلّمين الفعلية فقط، دون أسماء أو نتائج وهمية.

## الضيوف والخصوصية

لا يوجد نظام حسابات أو كلمة مرور. يربط ملف ارتباط HttpOnly وSameSite=Lax وSecure في الإنتاج تقدّم الضيف بمتصفحه. لا يُخزّن معرف المتعلّم في localStorage. يُطلب اسم مستعار اختياري للوحة الشرف؛ لا نطلب بريدًا إلكترونيًا أو اسمًا حقيقيًا.

التقدّم المعروض يبدأ من حالة ثابتة متوافقة مع SSR، ثم يُقرأ التخزين المحلي بعد التركيب وتُجلب النسخة الموثوقة من الخادم. تعذّر الاتصال لا يمحو التقدّم، وتظهر حالة المزامنة بوضوح. يجب الاتصال بالخادم للتحقق من إجابة جديدة؛ لا تُمنح نقاط محلية غير متحققة.

مسح بيانات المتصفح قد يفقد جلسة الضيف. إعادة التعيين من الإعدادات تحذف التقدّم وسجل المحاولات من الخادم وتحدّث النسخة المحلية بعد تأكيد صريح. هذه قيود طبيعية لنظام الضيوف؛ التعلّم مرتبط بالمتصفح وليس بحساب قابل للاستعادة على أجهزة أخرى.

## فحص الجودة

- `npx next typegen`
- `npm exec tsc -- --noEmit --pretty false`
- `npm run build`
- فحص الصحة: `/api/health`

مسارات الأسئلة لا تُعيد مفاتيح الإجابات. التحقق من المصدر وZod،และการ تصحيح على الخادم، واستعلامات Drizzle المعلّمة، وتقييد كشف لوحة الشرف، كلها مفعّلة. يضيف Next ترويسات أمان أساسية في `next.config.ts`.

## تخصيص المحتوى

عدّل البنك الكامل ثم شغّل `node scripts/build-question-index.mjs`. يتحقق المولّد من اكتمال المراحل وتفرّد المعرفات، وينشئ فهرسًا عامًا منزوع الإجابات تلقائيًا.

لاختبار الخادم أثناء تشغيله: `node scripts/smoke-test.mjs`. يعيد الاختبار تعيين تقدّم مستخدمه التجريبي في النهاية.

لفحص المتصفح اختياريًا: ثبّت Playwright بأمر `npm install --no-save playwright`، ثم `npx playwright install --with-deps chromium`، وشغّل `node scripts/browser-check.mjs` بينما الموقع يعمل. يفحص الكمبيوتر والهاتف والتقدّم و٢٥ حالة تجمع الصفحات وأبعاد الشاشة، وحالة تعطيل localStorage. أنشئ هجرة Drizzle عند تغيير المخطط، ولا تعدّل جداول الإنتاج يدويًا. الرسم والخطوط محلية داخل `public/` ولا تعتمد على خدمة صور أو خطوط خارجية أثناء التشغيل.
